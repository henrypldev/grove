The `@usegrove/sdk` package provides a TypeScript client for connecting to a Grove server over WebSocket, with optional React hooks for data fetching and real-time subscriptions.

## Installation

```bash
npm install @usegrove/sdk
```

## Quick Start

```typescript
import { GroveClient } from '@usegrove/sdk'

const client = new GroveClient({
  url: 'wss://your-machine.tail-net.ts.net/grove/ws'
})

await client.connect()

// List all teams
const teams = await client.teams.list()

// Create a team (uses REST for file upload support)
const team = await client.rest.teams.create({
  repoId: 'repo-id',
  task: 'Add dark mode to the settings page'
})

// Subscribe to real-time updates
client.subscribe([`team:${team.id}`])

client.on('activity', (event, channel) => {
  console.log(`[${event.type}]`, event.payload)
})

client.on('agent:update', (agent, channel) => {
  console.log(`Agent ${agent.id}: ${agent.status}`)
})
```

## Client Options

```typescript
interface GroveClientOptions {
  url: string                       // WebSocket URL (wss://...)
  deviceType?: 'mac' | 'mobile'    // Default: 'mac'
  autoReconnect?: boolean          // Default: true
  reconnectMaxRetries?: number     // Default: 10
  reconnectBaseDelay?: number      // Default: 1000ms
  pingInterval?: number            // Default: 30000ms
  rpcTimeout?: number              // Default: 30000ms
}
```

## Connection Management

```typescript
// Connect to the server
await client.connect()

// Check connection status: 'connecting' | 'connected' | 'disconnected'
console.log(client.status)

// Disconnect
client.disconnect()
```

The client automatically reconnects on connection loss with exponential backoff.

## RPC Methods

All RPC methods are available as namespaced async functions on the client. They communicate over WebSocket.

### Version

```typescript
const { version } = await client.version()
```

### Config

```typescript
// Server settings
const settings = await client.config.settings.get()
await client.config.settings.update({ settings: { key: 'value' } })

// Clone directory
const { cloneDirectory } = await client.config.cloneDir.get()
await client.config.cloneDir.set({ cloneDirectory: '/path/to/dir' })

// Browse directories
const { directories } = await client.config.listDirs({ path: '/Users' })
```

### GitHub

```typescript
const { repos } = await client.github.repos()
const { orgs } = await client.github.orgs()
const { repos: orgRepos } = await client.github.orgRepos({ org: 'my-org' })
```

### Repos

```typescript
// CRUD
const repos = await client.repos.list()
const repo = await client.repos.add({ path: '/path/to/repo' })
const cloned = await client.repos.clone({ fullName: 'owner/repo' })
await client.repos.delete({ id: repoId })

// Teams for a repo
const teams = await client.repos.teams({ id: repoId })

// Auto-detect setup steps
await client.repos.detect({ id: repoId })

// Setup steps
const steps = await client.repos.setup.list({ id: repoId })
await client.repos.setup.add({ id: repoId, name: 'Install', run: 'bun install' })
await client.repos.setup.update({ id: repoId, index: 0, name: 'Install', run: 'bun install' })
await client.repos.setup.delete({ id: repoId, index: 0 })
await client.repos.setup.reorder({ id: repoId, order: [2, 0, 1] })

// Scripts
const scripts = await client.repos.scripts.list({ id: repoId })
await client.repos.scripts.create({ id: repoId, name: 'Test', run: 'bun test' })
```

### Scripts

```typescript
await client.scripts.update({ id: scriptId, name: 'Test', run: 'bun test' })
await client.scripts.delete({ id: scriptId })
```

### Teams

```typescript
// List and get
const teams = await client.teams.list()
const team = await client.teams.get({ id: teamId })

// Lifecycle
await client.teams.archive({ id: teamId })
await client.teams.close({ id: teamId })  // Triggers PR creation

// Agents
const agents = await client.teams.agents.list({ id: teamId })
const agent = await client.teams.agents.spawn({ id: teamId, role: 'dev' })
await client.teams.agents.respawn({ teamId, agentId, prompt: 'Fix the failing test' })

// Activity and logs
const activity = await client.teams.activity({ id: teamId, since: lastEventId })
const logs = await client.teams.logs({ id: teamId })

// Documents
const { content: prd } = await client.teams.prd({ id: teamId })
const { content: design } = await client.teams.designDoc({ id: teamId })
const tasks = await client.teams.tasks({ id: teamId })
const { content: notes } = await client.teams.notes({ id: teamId })

// Setup management
await client.teams.setup.retry({ id: teamId })
await client.teams.setup.cancel({ id: teamId })
await client.teams.setup.stop({ id: teamId, step: 0 })
await client.teams.setup.start({ id: teamId, step: 0 })
const setupLogs = await client.teams.setup.logs({ id: teamId })

// Build management (Expo)
await client.teams.build.start({ id: teamId })
await client.teams.build.stop({ id: teamId })
const { status, output } = await client.teams.build.logs({ id: teamId })

// Dev server (Expo)
const { port } = await client.teams.devServer.start({ id: teamId })
await client.teams.devServer.stop({ id: teamId })
await client.teams.devServer.stdin({ id: teamId, input: 'r\n' })
const devLogs = await client.teams.devServer.logs({ id: teamId })

// Scripts
await client.teams.scripts.run({ teamId, scriptId })
await client.teams.scripts.stop({ id: teamId })  // stops the running script for this team
```

### Dashboard and Analytics

```typescript
// Dashboard overview
const { teams, metrics } = await client.dashboard()

// Git conflict detection
const conflicts = await client.conflicts()

// Usage metrics
const usage = await client.usage({ period: 'day' })
```

## REST Client

Some operations require REST (e.g. file uploads). These are available via `client.rest`:

```typescript
// Create a team with file attachments
const team = await client.rest.teams.create({
  repoId: 'repo-id',
  task: 'Implement the design in the attached mockup',
  files: [mockupFile]  // File objects (images, PDFs)
})

// Send a message with attachments
await client.rest.teams.sendMessage({
  id: teamId,
  text: 'Here is the updated spec',
  files: [specFile]
})
```

## Real-time Events

Subscribe to channels to receive real-time updates:

```typescript
// Subscribe to a specific team
client.subscribe([`team:${teamId}`])

// Subscribe to global updates
client.subscribe(['global'])

// Event handlers
client.on('activity', (event, channel) => {
  // TeamActivity event
})

client.on('log', (event, channel) => {
  // TeamLog event
})

client.on('team:update', (data, channel) => {
  // Partial team update (status changes, etc.)
})

client.on('agent:update', (data, channel) => {
  // Partial agent update (status, activity changes)
})

client.on('replay:batch', (events, channel) => {
  // Batch of historical events (from replay)
})

// Connection events
client.on('connected', () => {})
client.on('disconnected', () => {})
client.on('reconnecting', (attempt) => {})
```

### Replay

Catch up on events you may have missed:

```typescript
client.replay({ channel: `team:${teamId}`, sinceId: lastSeenEventId })
```

## React Hooks

The SDK includes React bindings built on [TanStack Query](https://tanstack.com/query) for type-safe data fetching and real-time subscriptions.

### Setup

Install peer dependencies:

```bash
npm install @tanstack/react-query react
```

Wrap your app with both providers:

```tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { GroveProvider } from '@usegrove/sdk/react'

const queryClient = new QueryClient()

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <GroveProvider url="https://your-machine.tail-net.ts.net/grove">
        <MyApp />
      </GroveProvider>
    </QueryClientProvider>
  )
}
```

`GroveProvider` accepts:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `url` | `string` | — | Server URL (automatically converts to WebSocket) |
| `autoConnect` | `boolean` | `true` | Connect on mount |
| `deviceType` | `'mac' \| 'mobile'` | `'mac'` | Device type for the connection |

### useGrove

Access the Grove client and connection status:

```tsx
import { useGrove } from '@usegrove/sdk/react'

function StatusBar() {
  const { client, baseUrl, status } = useGrove()
  // status: 'connecting' | 'connected' | 'disconnected'
  return <span>{status}</span>
}
```

### useQuery

Fetch data from GET endpoints with caching and automatic refetching. Paths and parameters are fully typed via `RouteMap`.

```tsx
import { useQuery } from '@usegrove/sdk/react'

// No params needed
const { data: teams, isLoading } = useQuery('/v2/teams')

// With path params
const { data: team } = useQuery('/v2/teams/:id', {
  params: { id: 'team-123' },
})

// With query params
const { data: activity } = useQuery('/v2/teams/:id/activity', {
  params: { id: 'team-123' },
  query: { since: lastEventId },
})

// With options
const { data } = useQuery('/v2/dashboard', {
  enabled: isConnected,
  refetchInterval: 5000,
  staleTime: 10000,
  gcTime: 300000,
})
```

### useMutation

Execute mutations (POST, PUT, DELETE, PATCH) with type-safe bodies and parameters. Automatically handles file uploads via FormData.

```tsx
import { useMutation } from '@usegrove/sdk/react'

// Create a team
const createTeam = useMutation('POST /v2/teams', {
  onSuccess: (data) => console.log('Created:', data),
  onError: (error) => console.error(error),
})

createTeam.mutate({
  body: { repoId: 'repo-id', task: 'Add dark mode' },
})

// With path params
const spawnAgent = useMutation('POST /v2/teams/:id/agents')

spawnAgent.mutate({
  params: { id: 'team-123' },
  body: { role: 'dev' },
})

// File uploads are detected automatically
const sendMessage = useMutation('POST /v2/teams/:id/messages')

sendMessage.mutate({
  params: { id: 'team-123' },
  body: { text: 'See attached', files: [imageFile] },
})
```

### useQuerySubscription

Subscribe to real-time WebSocket events. Automatically invalidates related queries when events arrive.

```tsx
import { useQuerySubscription } from '@usegrove/sdk/react'

// Subscribe to team activity
const { data: latestEvent, history } = useQuerySubscription('activity', {
  channel: `team:${teamId}`,
})

// Subscribe to agent updates
const { data: agentUpdate } = useQuerySubscription('agent:update', {
  channel: `team:${teamId}`,
})

// Conditional subscription
const { data: log } = useQuerySubscription('log', {
  channel: `team:${teamId}`,
  enabled: showLogs,
})
```

Events and their automatic query invalidations:

| Event | Invalidates |
|-------|-------------|
| `team:update` | `/v2/teams`, `/v2/dashboard` |
| `agent:update` | `/v2/teams/:id/agents` |
| `activity` | `/v2/teams/:id/activity` |
| `log` | `/v2/teams/:id/logs` |
| `replay:batch` | `/v2/teams/:id/activity` |

The `history` array keeps the last 200 events received for each subscription.
