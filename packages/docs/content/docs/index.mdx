Grove is an AI agent orchestration platform that manages teams of Claude agents working on your codebase. Create tasks from your phone, and Grove handles the planning, development, testing, and review — all running on your dev machine.

## Requirements

- [Bun](https://bun.sh)
- [Tailscale](https://tailscale.com) with Funnel enabled
- [ttyd](https://github.com/tsl0922/ttyd)
- [tmux](https://github.com/tmux/tmux)

## Installation

### Homebrew (recommended)

```bash
brew tap henrypldev/grove
brew install grove
```

### From source

```bash
git clone https://github.com/henrypldev/grove.git
cd grove
bun install
```

### Install dependencies

tmux and ttyd are required for terminal sessions:

```bash
brew install tmux ttyd
```

Tailscale is required for secure remote access:

```bash
brew install --cask tailscale
```

<Callout>
Tailscale needs to be set up on both your Mac **and** your phone before Grove can work remotely. See the [Tailscale Setup](/tailscale) guide for step-by-step instructions.
</Callout>

## Quick Start

### 1. Start the server

```bash
grove start
```

This starts the Grove server interactively. It checks that all dependencies are installed, starts the HTTP and WebSocket server, and sets up a Tailscale Funnel for external access.

### 2. Add a repository

Open the Grove app on your phone and add a repository — either clone from GitHub or point to a local directory on your Mac.

### 3. Create a team

Describe a task (e.g. "Add dark mode support to the settings page") and Grove will:

1. Create a git worktree for isolated work
2. Run your configured setup steps
3. Spin up an orchestrator agent that creates a PRD and design doc
4. Spawn specialist agents (team lead, developers, QA, reviewer) to implement the task
5. Open a pull request when the work is complete

### 4. Monitor progress

Track agent activity, review generated documents, and send messages to the team — all from your phone.

## How it works

1. **Grove server** runs on your Mac, exposing a REST API and WebSocket connection over Tailscale
2. **Teams** are the core unit of work — each team gets its own git worktree and set of agents
3. **Agents** are specialized Claude instances (orchestrator, PM, team lead, devs, QA, reviewer) that collaborate on your task
4. **The mobile app** connects to the server to create teams, monitor progress, and interact with agents
5. **The SDK** (`@usegrove/sdk`) provides a TypeScript client for building custom integrations
